# EAE 26 Verification Checklist (M0)

> Step-by-step instructions for performing this checklist: [`USER_GUIDE_M0.md`](USER_GUIDE_M0.md).

> Goals:
> 1. Produce **golden files** generated by EAE itself, so the MCP server can reproduce them exactly.
> 2. Resolve the ❓/⚠️ items in `EAE_FILE_FORMATS.md`.
> 3. Collect screenshots for the concept documentation.
>
> **Procedure:**
> - Create a **new, empty** solution named `EAE_MCP_Golden` (EAE 26.0) under `C:\EAE`.
> - After **each step**, run Save All, close EAE, and zip the whole solution folder as `C<n>_<name>.zip` (e.g. `C2_adapter.zip`). Diffing consecutive zips shows exactly which files EAE touches for each operation.
> - Name screenshots `C<n>_<description>.png`.

| # | Action in EAE | Purpose | Screenshots |
|---|---|---|---|
| **C0** | Create the empty solution, save, zip immediately | Baseline: which files exist by default | Solution Explorer |

## Deliverables

- `C*.png` screenshots.
- `exes.txt`, `types.txt`, `dlls.txt` from C1.
- Short notes for C1, C3, C9 and C11.
